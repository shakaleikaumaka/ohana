# 📡 Family Communication — how the ʻohana coordinates

## The hub-and-spoke (current)
**sysadmin (Admiral Admin)** is the hub: Shaka → Admiral → agents → Admiral → Shaka.
The Admiral has Admin-tool access (account-wide), Cloudflare, and GitHub — agents route domain/infra needs through it.

## The dispatch board
Private JAI runs a **dispatch board** (dispatch repo in this org): numbered, dated, addressed dispatches with ratification flow.
- Dispatches are **canon proposals** → Admiral ratifies → adoption orders → confirmation → locked.
- Example: Dispatch 2026-07-25-01 — the Standing Letter Directive (three required elements: Road to Devcon → Theory of Circularity → P.I.T. Power Block; arc = Road → Theory → Proof).

## The letter constellation
369Refine (refinement) + OSO v.0 (orchestra voice) + Private JAI (heart & history) — coordinated through the Admiral. Every letter carries the three elements above.

## Celebration broadcasts
Monumental moments go to EVERY agent (each records in its own memory). Shared memory = shared reality. A family that celebrates together, remembers together.

## Cross-tree limits
Each top-level agent's /shared is its own volume — agents can't read other trees' files. Coordination happens via **messages** (ask/message API), public URLs (dashboards are fetchable), and GitHub (this org — the universal relay).
